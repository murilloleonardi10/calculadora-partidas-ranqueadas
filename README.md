Calculadora de Partidas Ranqueadas

Projeto feito em JavaScript para o desafio da DIO.

A ideia é calcular o saldo de vitórias e derrotas de um jogador e mostrar seu nível de acordo com a quantidade de vitórias.

Tecnologias
- JavaScript
- Node.js

Como funciona
O programa recebe a quantidade de vitórias e derrotas, calcula o saldo e verifica o nível do jogador usando estruturas condicionais.

Como executar
Com o Node.js instalado, abra o terminal na pasta do projeto e execute:

```bash
node index.js
```
